# [剪輯筆記] The Prompt Report: A Systematic Survey of Prompt Engineering Techniques

- 作者：Sander Schulhoff 等 31 位作者（含 Philip Resnik、Jules White 等）
- 出處：arXiv:2406.06608（2024-06-06 首次提交；v6 修訂於 2025-02-26）
- 網址：https://arxiv.org/abs/2406.06608
- 擷取日期：2026-11-10（只讀了摘要頁）

## 摘要重點
- 問題：生成式 AI 已大量部署，使用者靠 prompt 與之互動；但領域很新，**術語不一致、對「什麼是好 prompt」的理解很零散**。
- 貢獻：建立提示技巧的結構化**分類法（taxonomy）**並分析應用：
  - 定義 **33 個詞彙**
  - 分類 **58 種 LLM 提示技巧**
  - 另有 **40 種**其他模態（非純文字）的技巧
- 提供提示工程的最佳實務與指引，包含針對 ChatGPT 等先進模型的建議。
- 對「自然語言前綴提示（prefix-prompting）」文獻做統合分析（meta-analysis）。
- 作者稱這是當時最完整的提示工程綜述。
