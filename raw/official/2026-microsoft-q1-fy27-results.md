# [剪輯筆記] Microsoft — FY27 第 1 季財報（Xbox 部分）

- 發布者：Microsoft 官方新聞稿與投資人關係頁
- 發布日期：2026-10-28
- 網址：https://news.microsoft.com/source/2026/10/28/microsoft-announces-first-quarter-results-2/ 、https://www.microsoft.com/en-us/Investor/earnings/FY-2027-Q1/metrics
- 擷取日期：2026-11-10
- 期間：2026 年 7–9 月（Microsoft FY27 Q1；FY27＝2026/7–2027/6）

## 重點
- Microsoft 全公司營收 92.3 十億美元，年增 19%（遊戲只占一小部分）。
- **Xbox 內容與服務營收年減 2%**（固定匯率 −1%）。
  - 定義：第一方與第三方內容（含遊戲與遊戲內購）、Game Pass 等訂閱、雲端遊戲、廣告。
- 過去一年的 Xbox 內容與服務年增率：FY26 Q1 +1%、Q2 −5%、Q3 −5%、Q4 −10%、FY27 Q1 −2%。全年 FY26 −5%。
- 官方頁面**沒有** Xbox 硬體營收的數字。

## 非官方（新聞報導，財報電話會議內容）
- Xbox 硬體營收年減 14%（主機銷量減少）。來源：VGChartz、Tweaktown。
- 下滑主因：第三方內容和 Game Pass 表現較弱，第一方內容成長抵銷一部分。
